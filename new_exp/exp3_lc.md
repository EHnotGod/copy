# 实验三：学习曲线——加数据只改极端检测率

**核心命题：** 增加训练量只提高极端样本的识别 recall，无法修复 R²(mid) 的持续失效。

## 实验设置

| 项目 | 说明 |
|---|---|
| LC 规模 | n = 100 / 300 / 600 / 1000 / 1500 / 2200 |
| 重复次数 | 3 seeds，均值汇报 |
| External val | 200 条（seed=42 固定，不参与 LC 采样）|
| Ridge | Qwen3-Embedding-8B 4096 dim，α ∈ {1,10,100,1000}，val R² 选最优 |
| KNN | CLIP-ViT-L/14 mean-pool 768 dim，k = min(50, n//3) |
| TFMLP | CLIP-ViT-L/14 per-token，2-layer self-attn，val early-stop |
| 指标 | R²(all)：全量；R²(mid)：y_true ∈ (0.10, 0.90)；cfg 均值 |
|      | delta-R²：d1 = q₅₀−q₁₀，d2 = q_tts−q₅₀（direct delta 预测）|

## 规律小结

- **R²(all) 随 n 单调增长**：三种 predictor 均稳定上升，每增一倍数据约 +0.05~+0.10。
- **R²(mid) 持续低位**：n=2200 时多数组合仍在 0 附近甚至为负，加数据无法修复。
- **delta-R² 更难学**：d2 = q_tts−q₅₀ 在多数组合上接近 0。
- **Ridge vs KNN**：大多数组合下 R² 相近，Ridge 在 n≥1000 时略优；KNN 在小 n 更稳定。
- **TFMLP**：小 n 时因过拟合不稳定，n≥600 后与 Ridge/KNN 接近。
