# §10 背包 DP 路由（Multiple-Choice Knapsack）

## 实验动机

本实验提出一种新路由方式：**多选背包 DP（MCKP）**，替代原 Lagrangian relaxation 路由。

**核心区别：**
- **Lagrangian 路由**：逐样本独立决策（argmax pred − λ×cost），通过 λ sweep 在 quality-cost 曲线上插值到 budget 处，不保证精确满足预算约束
- **DP 路由**：全局联合优化，每条 query 必须选且只选一个 config（10steps/50steps/tts），总 cost ≤ N×budget，最大化预测分总和，回溯得到精确最优分配

DP 路由等价于 Multiple-Choice Knapsack Problem（MCKP），是 Lagrangian 松弛对应的**原始问题精确解**。

## 算法细节

```
整数化：costs ×10 取整（qwen:[20,100,305], flux:[47,231,449], boogu:[43,215,648]）
总预算：B = floor(budget × N × 10) + 1
DP 状态：dp[c] = 前 i 条 query 已用总 cost 为 c 时的最大预测分之和
转移：对第 i 条 query 枚举 3 个 config j，dp[c+cost_j] = max(..., dp[c] + pred[i,j])
回溯：choice 矩阵逐层还原每条 query 的选择
复杂度：O(N × B)，N≈800，B≈80000，内存 ~50 MB
```

## 实验设置

- n_train=2200, n_val=200（seed=42 固定），3 split seeds 均值
- score mode 和 delta mode
- 预测器：Ridge / KNN / TFMLP
- 对比基线：exp4 Lagrangian routing n=2200
- 3 datasets × 3 models = 9 组

### Soft-RQ（§7，仅 gm，线性模型）

直接以 DP-RQ 为优化目标训练线性模型。固定 λ* 为训练集真实分上令 avg_cost ≈ budget 的值，loss = −E[softmax_τ(Wx+b − λ*·cost) · true]，超参 (τ, L2) 以 val DP-RQ 选。

| Dataset/Model | Oracle | 50steps | Ridge-Score (DP) | Soft-RQ | vs Ridge |
|---|---|---|---|---|---|
| gm/qwen | 0.4058 | 0.2482 | 0.3303 | **0.3328** | +0.0025 |
| gm/flux | 0.4335 | 0.3321 | **0.3458** | 0.3405 | −0.0052 |

> qwen 上 Soft-RQ 小幅提升（+0.0025），最优超参 τ≈0.1~0.2、L2≈1~5，λ*=0.0107。
> flux 上反而下降（−0.0052），λ*=0.0005 极小（训练集 avg_cost 已接近 budget，几乎无路由空间），softmax 在此场景下退化为 argmax，梯度稀疏导致训练不稳定。

### §8 更多路由/损失变体（仅 gm）

- **B 加权Ridge**：训练时对 λ* 决策边界附近样本加高权重（`w ∝ margin^{-α}`），聚焦于难分样本
- **C Multi-λ Soft-RQ**：在 λ ∈ [0, 5λ*] 区间均匀采样 K=15 个 λ 取平均，修复单点 λ* 退化
- **D Pairwise SVM**：对 10vs50、50vstts 两段分别训练 LinearSVC，decision function 直接路由
- **E Isotonic 校准**：Ridge 预测后对每个 cfg 做单调回归校准，撑开被压缩的预测分布

| Dataset/Model | Oracle | 50steps | Ridge | B 加权 | C Multi-λ | D SVM | E Isotonic |
|---|---|---|---|---|---|---|---|
| gm/qwen | 0.4058 | 0.2482 | 0.3303 | 0.3175 | **0.3335** | 0.3021 | 0.3255 |
| gm/flux | 0.4335 | 0.3321 | **0.3458** | **0.3471** | 0.3444 | 0.3375 | 0.3434 |

_vs Ridge_：qwen: B=−0.013, C=**+0.003**, D=−0.028, E=−0.005；flux: B=**+0.001**, C=−0.001, D=−0.008, E=−0.002

**Delta-Full 结论：**
- **大部分场景比 Delta 差**，最严重在 gm/qwen（R: −0.0250, K: −0.0635, T: −0.0369）和 unigen/qwen（R: −0.0310, K: −0.0508, T: −0.0435）
- **gm/flux 是例外**：ridge_df 0.3475 > ridge_d 0.3458（+0.0017），表现最好
- **根本原因**：d_full 把 q50−q10（low-cost gain）和 qtts−q50（high-cost gain）混合为一个信号，路由时无法区分"值不值得升一档"还是"值不值得升两档"，信号质量劣于 d1/d2 分开预测；对于 qwen（成本差异大：2/10/30.5）尤其有害
- **与 user 发现一致**：delta_r2_d2 = R²(qtts-q50) 是路由质量的唯一可靠预测指标；d_full 混入 d1 噪声，稀释了 d2 信号

## 实验结论

- **DP vs Lagrangian 几乎等价**：Score mode 下 27 个组合 |Δ| ≤ 0.0009，说明 Lagrangian 扫 λ 对偶间隙接近 0，精确 DP 不带来额外收益。
- **exp4 的 delta bug 影响了 Ridge/KNN**：修复后与 Ridge-Score DP 持平，说明 delta target 本身无优势。
- **TFMLP-Delta 在部分 setting 略优于 TFMLP-Score**（最大 +0.008 gm/qwen），但不稳定，且整体不如 Ridge。
- **Delta-Full（qtts−q10）基本不如 Delta（分开 d1/d2）**：混合信号破坏路由决策能力，gm/qwen 上 Ridge 跌 0.025，KNN 跌 0.064。
- **目标优化方向有效但收益有限**：Soft-RQ / Multi-λ 在 qwen 上 +0.003，在 flux（λ*≈0，路由空间小）上退化。
- **加权Ridge（B）在 qwen 上反而下降**（−0.013），说明 2200 样本下边界加权引入了过拟合。
- **Pairwise SVM（D）最差**：线性 SVM 在 4096 维特征下过度正则化，信号丢失。
- **瓶颈不在路由算法**：所有路由/损失变体的收益均在 ±0.003 量级，远小于预测器 R²（≈0.15）本身的限制。
