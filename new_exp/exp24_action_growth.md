## 设置

- 数据：GenEval2 GM 与 AM；固定 train/val/test = 2200/200/800，split seed=42。
- 预算：`E[c]≤10`，与 `qwen_50steps` 的成本相同。
- Predictor：仅 Ridge；复用 §23 中按 instruction 正确对齐的预测，不需要 GPU。
- 指标：`累计收益 = 当前质量 − Qwen50质量`；`单步收益 = 加入当前动作后的质量 − 上一步质量`。
- 顺序：Q50 → Q10 → QTTS → F10 → F50 → FTTS → B10 → B50 → BTTS → F4B4。
- 注意：单步收益依赖加入顺序，它表示条件边际贡献，不是动作的独立贡献。

![action growth](figs/exp24_action_growth.svg)

## 主要结论

- GenEval2 GM：完整 A10 相对 Qwen50 的 Ridge 总收益为 +0.1324，可分为 LP 静态动作池收益 +0.1273 和 Ridge−LP learned routing 收益 +0.0052。
- GenEval2 AM：完整 A10 相对 Qwen50 的 Ridge 总收益为 +0.0717，可分为 LP 静态动作池收益 +0.0619 和 Ridge−LP learned routing 收益 +0.0098。
- 两个指标的最佳 Ridge 前缀都是 A8；继续加入 `boogu_tts` 和 `flux4b_4steps` 没有带来可学习收益。
- 主要正向台阶来自 `qwen_tts`、`flux_10steps`、`boogu_10steps`；50steps/TTS 高成本动作中的若干项只提高 Oracle，Ridge 基本没有利用。

## 解释口径

Oracle 曲线表示动作池新增后系统机会的变化；LP 曲线表示无需识别 prompt 的静态混合收益；Ridge−LP 才是 learned router 超越静态动作先验的实例级收益。若新增动作提高 Oracle、但不提高 Ridge，说明它有互补性，但当前 predictor/router 没有稳定利用。
