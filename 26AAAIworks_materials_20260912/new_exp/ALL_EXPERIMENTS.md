## §1 分数分布

**核心命题：** 极端样本（0 分 / 满分堆积）决定后续 R² 解读方式。

### 实验动机

若分数分布两端堆积严重（大量 0 分或满分），predictor 只需识别极端样本就能获得虚高的 R²(all)，但对真正需要细粒度决策的中间区间一无所知。本节先摸清三个数据集的实际分布，为后续 R²(mid) 的解读提供基准。

> 极端阈值 0.05 / 0.95 与后续 §2 R²_mid 的截断（y ∈ (0.10, 0.90)）略有不同：分布统计用更宽松的 0.05/0.95 捕捉两端绝对堆积；§2 用更保守的 0.10/0.90 确保去掉训练信号最强的极端样本后再评估中间区间预测力。

### 实验结论

- **GenEval2 GM**：几何均值的压制作用使低分堆积严重（qwen 10/50steps frac<0.05 超过 25%）；高分几乎没有堆积（frac>0.95 普遍 < 10%）。
- **GenEval2 AM**：算术均值跨维度补偿，两端堆积均极少（frac<0.05 全部 0%）；分数集中在 0.5–0.9 的中间区间。
- **UniGenBench**：任务相对简单，高分堆积严重（boogu tts frac>0.95 超过 55%）；低分几乎不存在。
- GenEval2 与 UniGen 呈镜像关系：前者 0 分多、满分少；后者满分多、0 分极少。这一差异决定后续 §2 中 R²(all) 的来源方向。

## §2 全样本 R²(all) / R²(mid) / delta-R² capacity

**核心命题：** 全样本 R²(all) 看起来不错，但中间区间直接塌陷；delta-R² 揭示不同 predictor / 配置的实际可分程度。

### 实验动机

验证 §1 的猜测：R²(all) 是否被极端样本虚高？剔除两端（y ∈ (0.10, 0.90)）后 R²(mid) 是否塌陷？delta-R²（预测档位间增益的能力）是否揭示更真实的可分程度？

### 实验设置

| 项目 | 说明 |
|---|---|
| 训练集 | pool 共 2400 条，固定 seed=42 切 200 条 external val，剩余 2200 条；3 seeds（0/1/2）均值 |
| **R²(all)** | 全 test 集 R² |
| **R²(mid)** | 仅 y_true ∈ (0.10, 0.90) 子集的 R² |
| **delta-R²** | d1 = q₅₀ − q₁₀，d2 = q_tts − q₅₀；Ridge 从绝对预测相减；KNN/TFMLP 直接预测 delta（M=2）|

### 实验结论

- **R²(all) 虚高，R²(mid) 普遍塌陷**：三种 predictor 在全样本上的 R²(all) 普遍在 0.1–0.5 之间，看起来有预测力。但剔除两端（y ∈ (0.10, 0.90)）后，R²(mid) 大幅下降甚至为负——GM 的低分堆积、UniGen 的高分堆积是 R²(all) 的主要来源，中间区间几乎无信号。
- **KNN / TFMLP 与 Ridge 的对比**：KNN（CLIP 768 dim）的 R²(all) 普遍低于 Ridge（Qwen3 4096 dim），说明 Qwen3 embedding 信息密度更高。R²(mid) 上三种 predictor 差距收窄——中间区间的瓶颈是信号稀薄而非特征质量。TFMLP 的 R²(all) 介于 KNN 和 Ridge 之间，但 R²(mid) 同样无法修复。
- **delta-R²：d1 vs d2**：d1（q₅₀ − q₁₀，低档→中档增益）在 GM 上普遍为负；d2（q_tts − q₅₀，中档→高档增益）略好但仍接近零。UniGen 上 delta-R² 相对更高（Ridge d1 最高达 +0.30），与后续 §4 路由收益更强的结论一致。
- **KNN 和 TFMLP 的 delta-R² 均显著低于 Ridge**——直接预测 delta 并不比从绝对预测相减更强，非线性的 TFMLP 也未带来提升，说明瓶颈在数据信号本身。

## §3 学习曲线——加数据只改极端检测率

**核心命题：** 增加训练量只提高极端样本的识别 recall，无法修复 R²(mid) 的持续失效。

### 实验动机

§2 的低 R²(mid) 是否是数据量不足造成的？若是，R²(mid) 应随 n 增加持续修复；若 R²(all) 增长而 R²(mid) 不动，则说明瓶颈是信号本身，加数据无法解决。

|  | delta-R²：d1 = q₅₀−q₁₀，d2 = q_tts−q₅₀（direct delta 预测）|

## §4 路由质量 LC

### 实验动机

§2–§3 在预测质量（R²）层面分析，但最终目标是路由决策收益。能否用少量标注样本训练预测器，把每条 query 路由到性价比最高的 cfg，从而在 budget 不变的情况下超过"一律跑 50steps"？本实验系统评估：三种预测器（Ridge / KNN / TFMLP）× 两种预测范式（score mode / delta mode）× 三个数据集 × 三个模型，以及随 n 增加时的学习曲线与参考线差距。

### 实验设置

- 路由策略：Lagrangian 松弛，扫描 λ，argmax(pred_score − λ×cost)
- Score mode：直接预测绝对分数；Delta mode：预测 d1=q50−q10, d2=qtts−q50
- Budget = 各模型 50steps 对应 cost（qwen=10.0, flux=23.1, boogu=21.5）
- Cost 表：qwen [2.0/10.0/30.5]，flux [4.7/23.1/44.9]，boogu [4.3/21.5/64.8]（10/50/tts）
- Oracle：测试集真实分数路由（上界）；LP：全 pool 均值凸包插值（下界）

## §5 图片 Seed 数量敏感性

### 实验动机

- **实践意义（精度）**：若只关心路由决策，k=1 已足够；若关心绝对分值预测，建议 k≥3。

## §6 Mid-pool vs All-pool 路由对比

### 实验动机

§4 的训练池包含所有样本（含极简单/极困难），可能引入噪声：极简单样本三个 cfg 分数接近上限，极困难样本接近下限，对预测器的判别边界贡献不大，甚至可能干扰拟合。本实验验证：**只用"中等难度"样本（50steps 分数 ∈ (0.10, 0.90)）训练，路由效果能否相比 all-pool 有所提升**？

## §7 类别内打乱消融实验

### 实验动机

predictor 路由超过 50steps 基线的原因有两种可能：（1）学到了 prompt 级别的难度排序信号（真正有价值）；（2）学到了训练集的类别级别分布偏置（可能虚高）。通过类别内打乱（intra-shuffle）破坏 prompt 级信号但保留类别级分布，与全局打乱（full-shuffle）和正常训练（real）对比，定位信号来源。

### 实验设置

- n=2200，score mode only，3 seeds，所有预测器
- **Real**：正常训练，predictor 能学到 per-prompt 难度
- **Intra-shuffle**（仅 GM/AM）：类别内随机打乱质量标签（position/count/other），破坏 prompt 级信号，保留类别级分布
- **Full-shuffle**：全局随机打乱，彻底破坏所有信号
- GM/AM 类别划分：关键词匹配 instruction（position / count / other）
- UniGen：使用自由格式中文 prompt，无结构类别，跳过 intra-shuffle（只跑 real / full-shuffle）

- **结论**：predictor 的提升来自真实的 per-prompt 难度评估信号，而非人为的类别分布偏置，路由框架的有效性得到验证。

## §8 路由收益与预测指标的相关性

### 实验动机

路由收益的高低究竟由哪类预测指标决定？直觉上研究者常用绝对分 R²（如 R²(q50)）来衡量预测器质量，但路由决策依赖的是样本间的**相对难度排序**（哪条 query 在 tts 有增益），而非绝对分值的准确性。本实验在 test 集上同时计算多类指标，以路由收益为因变量，通过 Pearson 相关系数定量对比各指标的预测力，证明 delta 指标才是真正的 routing-relevant signal，绝对分指标不可信。

### 实验设置

- 数据点：Ridge / KNN / TFMLP × 3 datasets × 3 models × 3 seeds = 27 点/predictor，共 81 点
- 固定 n=2200，score mode
- 所有指标均在 **test 集** 上计算（非 train/val）
- 路由收益 = route_quality(score_mode) − always_50steps
- 指标分两组：Unreliable（绝对分）vs Reliable（delta 分）

### Pearson r 汇总（n=2200，各 predictor 分列）

| 指标 | 类型 | Ridge r | KNN r | TFMLP r |
|------|------|---------|-------|---------|
| `abs_r2_50` | Unreliable | 0.071(p0.724) | 0.105(p0.601) | -0.131(p0.514) |
| `abs_r2_mean` | Unreliable | 0.050(p0.804) | 0.107(p0.596) | -0.138(p0.492) |
| `abs_sp_50` | Unreliable | -0.162(p0.421) | -0.192(p0.336) | -0.102(p0.613) |
| `delta_r2_d1` | Reliable | 0.272(p0.170) | 0.006(p0.977) | 0.050(p0.805) |
| `delta_r2_d2` | **Reliable** | **0.749(p<.001)** | **0.808(p<.001)** | **0.499(p0.008)** |
| `delta_r2_mean` | Reliable | 0.561(p0.002) | 0.500(p0.008) | 0.258(p0.193) |
| `delta_sp_mean` | Reliable | 0.532(p0.004) | 0.267(p0.178) | 0.550(p0.003) |

### 图表

![exp8 metrics scatter](figs/exp8_metrics_scatter.png)

### 实验结论

- **绝对分指标全部不相关**：`abs_r2_50`、`abs_r2_mean`、`abs_sp_50` 在三个 predictor 上 r 均接近 0（最高仅 0.107），p 值全部无显著性（p>0.3），散点呈水平云团。说明绝对分预测精度完全无法预测路由收益，用它来选 predictor 是误导性的。
- **delta_r2_d2 是唯一可靠指标**：R²(Δ₂=qtts−q50) 在 Ridge r=**0.749**、KNN r=**0.808**、TFMLP r=**0.499**，三个 predictor 均显著（p<0.01），且 r 值最高。图中散点有明显的正相关趋势，是所有指标中唯一在三个 predictor 上均成立的信号。
- **d₁ 完全无效**：`delta_r2_d1`（R²(q50−q10)）r 在 0.006–0.272 之间，均不显著。说明 10steps vs 50steps 的差值对路由几乎没有贡献，路由收益完全由 tts 的边际增益决定。
- **delta_sp_mean 次之**：对 Ridge（r=0.532）和 TFMLP（r=0.550）显著，但对 KNN 不显著（r=0.267, p=0.178）。
- **实践意义**：评估路由 predictor 时，**只用 `delta_r2_d2` = R²(qtts−q50)** 作为核心指标即可；绝对分 R² 高低与路由好坏无关，不应作为 predictor 选型依据。

## 总结

| 实验 | 核心问题 | 主要结论 |
|---|---|---|
| §1 分数分布 | 三数据集分布形态如何？ | GM 低分堆积、UniGen 高分堆积，AM 居中；极端样本主导 R²(all) |
| §2 R²(all)/R²(mid)/delta-R² | 全样本 R² 是否虚高？ | R²(all) 被极端样本虚高；R²(mid) 在中间区间普遍塌陷；delta-R² 仅 UniGen/Ridge 有正值 |
| §3 学习曲线 | 加数据能修复 R²(mid) 吗？ | R²(all) 随 n 增长；R²(mid) 不修复；UniGen delta-R² 随 n 持续增长 |
| §4 路由质量 LC | 预测路由能超过 50steps 吗？ | 全面超过 50steps；UniGen 收益最大；n≥800 后收益递减；Score≈Delta mode |
| §5 图片 Seed 敏感性 | k=1 seed 够用吗？ | k=1 到 k=5 几乎无差（<0.003），单 seed 标注即可 |
| §6 Mid-pool vs All-pool | 过滤中间难度样本有帮助吗？ | Mid-pool 不如 All-pool，UniGen 差距明显（~0.015），过滤得不偿失 |
| §7 类别内打乱 | 信号来自 prompt 级排序还是类别偏置？ | Real >> Full-shuffle 一致成立；信号来自真实 per-prompt 难度 |
| §8 路由收益相关性 | 哪类指标真正预测路由收益？ | 绝对分 R² 完全不相关；只有 R²(qtts−q50) 显著预测路由收益（r=0.75~0.81）|
