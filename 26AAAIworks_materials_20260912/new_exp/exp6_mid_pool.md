# §6 Mid-pool vs All-pool 路由对比

## 实验动机

exp4 的训练池包含所有样本（含极简单/极困难），可能引入噪声：极简单样本三个 cfg 分数接近上限，极困难样本接近下限，对预测器的判别边界贡献不大，甚至可能干扰拟合。本实验验证：**只用"中等难度"样本（50steps 分数 ∈ (0.10, 0.90)）训练，路由效果能否相比 all-pool 有所提升**？

## 实验结论

- **Mid-pool 整体不如 All-pool**，在 UniGen 上差距尤为明显（Ridge 相差 ~0.015，KNN/TFMLP 相差 ~0.005-0.010）。
- **GM 上两者几乎持平**，Mid-pool 偶尔略好（差距 < 0.003），差异可忽略。
- **AM 上 Mid-pool 对 Ridge/KNN 有微弱优势，TFMLP 略差**，整体差距极小（< 0.003）。
- **结论：过滤 mid 样本得不偿失**。原因是 mid_pool 覆盖面窄（n_mid 仅 1000-2200，远少于 all-pool 的可采样上限），同时去掉了极端样本后 predictor 泛化到全测试集时精度反而下降。All-pool 训练集分布更广，泛化性更强。

## 实验设置
- Mid-pool：train/val 只用 50steps ∈ (0.10, 0.90) 的样本，n=2200（或 mid 上限），3 seeds
- All-pool：exp4 n=2200 结果（已有）
- test 全集，score mode only
