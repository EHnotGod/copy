# 实验五：Oracle gap 的反事实分解（budget=10.0）

极端样本 = test 真实 anchor（qwen_50steps）score ≤0.05 或 ≥0.95；
CF-extreme/CF-mid = 极端/中段样本的预测换成真值后的路由质量（同 λ 扫描口径）。
gap 分解百分比 = (CF − base) / (Oracle − base)。
