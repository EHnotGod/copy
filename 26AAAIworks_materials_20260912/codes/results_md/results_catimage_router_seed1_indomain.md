## 各方法选中 tts 的分析（seed=1，预算≤50）

**指标说明**：
- **选中tts均分**：该方法选了 tts 的那些 case，其 tts 档真实分的均值。会受「tts 大盘本身强」干扰，不能单看。
- **tts比其他最好档**（关键）：选中 tts 的 case 里，tts 真实分 − 该 case 其他四档最高分，再取均值。>0 表示「选中的 tts 确实比别的档强」，是排除大盘干扰后判别力的干净证据。

| benchmark | 方法 | 选tts数 | 选tts率 | 选中tts均分 | tts比其他最好档 |
|-----------|------|-------:|-------:|----------:|--------------:|
| geneval2 (tts均分44.8) | LP | 384 | 48.0% | 46.2 | +1.3 |
| | KNN | 339 | 42.4% | 49.1 | +1.1 |
| | TFMLP | 290 | 36.2% | 44.9 | **+4.6** |
| corebench (58.6) | LP | 378 | 35.0% | 60.8 | +4.7 |
| | KNN | 431 | 39.9% | 59.9 | **+8.5** |
| | TFMLP | 440 | 40.7% | 57.6 | **+9.6** |
| wise (88.2) | LP | 350 | 35.0% | 88.1 | +1.0 |
| | KNN | 417 | 41.7% | 91.6 | +5.3 |
| | TFMLP | 356 | 35.6% | 88.9 | **+6.5** |
| coco (95.0) | LP | 428 | 35.7% | 95.1 | −1.9 |
| | KNN | 504 | 42.0% | 95.0 | −1.6 |
| | TFMLP | 644 | 53.7% | 94.4 | −2.1 |

**结论**：
- 有难易信号的 bench（geneval2/corebench/wise）：学习式路由选中 tts 的「边际优势」显著高于盲选 LP（如 corebench TFMLP +9.6 vs LP +4.7），说明它们真的挑中了「tts 确实更强」的 case，而非靠 tts 大盘高瞎选。
- coco（无信号）：三方法边际全为负（−1.6~−2.1），选中的 tts 还不如其他档；TFMLP 甚至选了 53.7% 的 tts（最多）却边际最差，完全失效。
- **「选中tts均分」会骗人**：LP 在 geneval2 选中均分 46.2 看似不低，但边际仅 +1.3（几乎等于瞎选）；判别力要看边际，不看均分。

## 分析（跨 seed=0 / seed=1 对照）

下表是 TFMLP@50 − LP 的分差，同时列 seed0 / seed1（正=TFMLP 赢）：

| bench | 总分差 s0 / s1 | 需要花钱 s0 / s1 | 中间 s0 / s1 | 该省钱 s0 / s1 |
|-------|:---:|:---:|:---:|:---:|
| geneval2 | +0.1 / +2.8 | −2.0 / +3.4 | +2.6 / +2.6 | +6.9 / +0.3 |
| corebench | +1.0 / +2.5 | +0.8 / +3.9 | +1.2 / +0.4 | +2.1 / +1.5 |
| wise | +1.0 / +2.9 | +0.9 / +6.7 | +0.7 / +0.4 | +6.2 / +4.9 |
| coco | −1.5 / +0.0 | −14.9 / −3.2 | +0.1 / +0.4 | +7.2 / +2.9 |

**稳健结论（两个 seed 都成立）**：

1. **有难易信号的 bench（geneval2 / corebench / wise）：TFMLP 总分稳赢 LP**，两 seed 分差均为正（+0.1~+2.9）。这是学习式路由「有判别力」的核心证据。
2. **coco（无难易信号）：TFMLP 打不过 LP**——总分 s0 −1.5、s1 +0.0，基本打平甚至输。尤其「需要花钱」的 case 上两 seed 都大幅落后（−14.9 / −3.2），说明 coco 各档分数太接近、没有可学的难易梯度，学习式路由退化。

**不稳、不宜单独强调的部分**：

- TFMLP 到底赢在「需要花钱」还是「该省钱」的 case，**两个 seed 不一致**：geneval2 需要花钱 s0=−2.0 但 s1=+3.4；该省钱 s0=+6.9 但 s1=+0.3。
- 原因：LP 是随机基线，其混合的两个档随 seed 变化（seed0 混 fx9b10+tts，seed1 混档不同），导致「分类到某一类里 LP 恰好选了什么」发生漂移。因此「胜因归到哪一类 case」是 LP 基准的伪影，不是 TFMLP 本身的稳定性质。
- **正确的读法**：只看「总分是否稳赢」和「有信号 vs 无信号(coco)的对比」，不要把胜因钉死在某一类 case 上。
