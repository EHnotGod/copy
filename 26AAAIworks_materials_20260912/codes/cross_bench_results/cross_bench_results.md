# Cross-Bench RF 实验结果

**训练池**：geneval2 / corebench / wise / unigen 各 400 条 edit-gen + coco 400 条 raw，共 2000 条。
**测试集**：各 benchmark 的 edit-raw 全量（coco 取剩余 1600 条）。
**模型**：Random Forest (n=300, min_samples_leaf=3)，特征为 Qwen3-Embedding-8B instruction embedding。
**预算**：DP@50（每 case 平均 50 步算力）。

## 指标说明

| 指标 | 含义 |
|:---|:---|
| oracle | 已知所有分数时的最优 DP 分配得分 |
| DP@50 | RF 路由后的实际得分（预算=50×N）|
| %oracle | DP@50 / oracle，越接近 100% 越好 |
| ACC | RF 分配档位与 oracle 档位逐 case 一致率 |
| sp_tts | RF 预测 tts 分数与真实 tts 的 Spearman 相关 |
| pstd/tstd | 预测标准差 / 真实标准差（<1 说明预测偏保守）|
