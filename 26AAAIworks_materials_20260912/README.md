# 26AAAIworks 实验材料交流包

整理快照：2026-09-12。解压后从本文开始，所有记录、统计结果和引用图表均按包内相对路径浏览，不需要连接原集群。没有网页；用支持 Markdown 的阅读器即可查看表格和图片。

## 建议阅读顺序

1. [写作主线与证据对应](writing/README.md)：了解目前能够支持的结论与限制。
2. [项目导航](项目导航.md)：查看研究问题和资料分工。
3. [实验目录](new_exp/README.md)：按主题查找 §1–56 的实验主记录。
4. [修复与核对记录](修改日志.md)：了解数据对齐、训练/测试重合修复与重跑范围。
5. [正式数据构建记录](new_exp/construction_v2_record.md)：查看 CoreBench/WISE v2 的正式文本与首轮评测状态。

## 目录与阅读口径

| 目录 | 内容 |
|---|---|
| `new_exp/` | 按主题整理后的实验 MD、图表、旧结构化结果，以及 `results/prompt_disjoint_v1/` 下的修复结果 |
| `writing/` | 当前写作入口与五份明确标记的历史草稿 |
| `exp1_absolute_predict/`、`exp_815/`、`exp_catimage818/` | 早期预测审计、无 TTS 七动作实验与 CATImage 记录 |
| `codes/` | 早期结果说明、被记录引用的方法源码和正式 v2 文本 |
| `docs/` | 数据/记录核对材料与原项目操作说明 |

已重跑实验优先阅读页首“修复后的当前结果”；下方折叠内容是旧协议或旧结果。其余历史实验没有因进入交流包而获得重跑认证。GM/AM 共享 prompt 来源；Joint、LOBO、不同动作库与不同测试支持分别判断。

本包带齐阅读与核对所需材料。源码仅用于讨论方法，不包含完整模型运行环境、训练标签和特征缓存，不能据此承诺重新训练。结果 JSON 中的原环境路径只是历史出处；对应分数和图表已在包内。被省略的运行附件逐项列在 [附件范围](附件范围.md)。

标签补齐与 Hope 已暂缓；本包数值沿用现有结果，没有新增生成或训练实验。

## 核验材料是否完整

提供 [文件清单](文件清单.json) 与 [打包校验结果](校验结果.json)。可选使用 Python 3.9 或更新版本，从任意目录执行解压包中的校验脚本：

```bash
python3 verify_package.py
```

该脚本只使用标准库，检查文件哈希和 Markdown 本地链接，不联网、不启动模型、不修改文件。转发时发送整个 ZIP，避免单独复制 MD 后遗漏图表。
