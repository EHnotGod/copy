# CATImage @ B=50：KNN / TFMLP 对比（gen训练 vs 全量训练）

**评估方式**：λ-sweep 曲线上取 avg_cost ≤ 50 的最优点的质量分（CATImage 原始框架，预算 B=50×N）。
**ACC**：DP 路由下与 oracle DP 分配的逐 case 档位一致率。
**gen训练**：自身 benchmark gen 库 300 train / 100 val，seed 0/1/2 均值。
**全量训练**：geneval2/corebench/wise/unigen/coco 混合 2000 条，seed 0/1/2 均值。
