实验设置详解

  目标

  给定一批文生图 prompt，如何动态分配算力（steps 数）到每个 prompt 上，让整体质量最高。核心假设：不同 prompt 
  从多步生成中受益不同

  数据组织

  三档分数

  每条 prompt 都跑 3 档、取多 sample 均值，得到 3 个真实分数：
  - 10steps：直接 T2I，10 步
  - 40steps：直接 T2I，40 步
  - tts (test-time scaling, 80 tokens)：两阶段方法，共 40+40 步

  两种 tts 方法（v5 vs v6 对照）：

  ├────────┼────────────────────────────────────┼──────────────────────────────────────────────┼─────────────────────┤

  每条 raw 长这样：
  {"case_id":"1","instruction":"...","scores":{"10steps":0.75,"40steps":0.82,"tts":0.94}}

  模型：Prompt → 预测 delta

  特征：Qwen3-Embedding-8B 编码 prompt → 4096 维向量（用了 codes/.cache_embed/*.npy 缓存）。

  输出：不是直接预测 3 个分数，而是预测两个 delta：
  - delta_40_10 = score_40 - score_10
  - delta_tts_40 = score_tts - score_40
  
  这样 DP 分配时只需要模型预测增益，真实的 s10 分数（用于初始 base）无需模型，减小学习负担。这是 --strategy delta。

  回归器 MLP：
  Linear(4096 → 512) → ReLU → Dropout → Linear(512 → 128) → ReLU → Linear(128 → 2)
  - --mlp_hidden 512 128
  - --alpha 3.0（对应 weight_decay = alpha/10 = 0.3）
  - --lr 0.001
  - --max_iter 5000
  - --mlp_batch 200
  - --patience 10（early stopping）
  - --normalize_scores（per-file min-max，防止不同数据集分数范围差异影响回归）

  损失：MSE (2维回归)。

  训练规模：6 数据源 × 300 = 1800 训练样本 / 6 × 100 = 600 验证。

  分配算法：动态规划 (DP)

  给定 n 个 case，每个 case 3 个候选（10/40/80 steps，成本单位 1/4/8），一个总预算 B。找 alloc 使 Σ 预测收益最大：

  opts[i] = [(cost=1, score=s10),
             (cost=4, score=s10 + δ40),
             (cost=8, score=s10 + δ40 + δtts)]

  背包 DP：dp[i][w] = max(dp[i-1][w-cost_j] + score_j for j in 3 choices)。

  三档预算：
  - DP@25：B = n × 25（预算紧，多数 case 分 10）
  - DP@40：B = n × 40（标准预算，跟"全跑 40 步"同 token 数）
  - DP@60：B = n × 60（宽裕预算，多数 case 分 40+）

  评估：拿分配结果去查真实分数 → 取平均。

  Baseline

  同预算下的"不用模型"对照：

  ┌───────────┬───────────────────────────────────────────────┬────────────────┐
  │   名字    │                     方法                      │    平均预算    │
  ├───────────┼───────────────────────────────────────────────┼────────────────┤
  │ H10/40@25 │ 一半 case 分 10、一半分 40                    │ (10+40)/2 = 25 │
  ├───────────┼───────────────────────────────────────────────┼────────────────┤
  │ Rand@40   │ 全 10 起步，随机升级到 40 或 80，直到预算耗尽 │ 40             │
  ├───────────┼───────────────────────────────────────────────┼────────────────┤
  │ H40/80@60 │ 一半 case 分 40、一半分 80                    │ (40+80)/2 = 60 │
  ├───────────┼───────────────────────────────────────────────┼────────────────┤
  │ CT        │ 用真实 delta 做 DP（oracle）—— 理论上限       │ 40             │
  └───────────┴───────────────────────────────────────────────┴────────────────┘

  Baseline 都跑 seed=0/1/2 取平均。
