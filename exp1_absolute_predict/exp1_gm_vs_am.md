# 实验记录：绝对性能预测测不准

[TOC]

**核心命题：** 对 prompt x、配置 k，在生成之前能否从 prompt 文本预测期望质量 q_k(x)？

本文档用六组实验逐层说明答案是"测不准"，且这个结论与评分方式、数据集、predictor 选择、训练数据量均无关。

**Predictor：** Qwen3-Embedding-8B（4096 维）对 prompt 文本编码，接 StandardScaler + Ridge regression。Ridge 正则系数 α ∈ {1, 10, 100, 1000}，用固定 200 条 external val（seed=42，从 pool 中随机切）的 R² 选最优 α，再用全量训练集重新拟合；测试集独立，全程不参与训练或调参。每组实验 3 个随机 seed 均值汇报。

**生成模型与配置：**
- Qwen-Image-2512（qwen）：3 档推理步数，cost = 10 / 50 / 100 TFLOPs
- FLUX.2-Klein-9B（flux）：3 档推理步数，cost = 23.1 / 115.5 / 231.0 TFLOPs
- Boogu-Image（boogu）：3 档推理步数，cost = 10 / 50 / 100 TFLOPs
- 3 档分别对应 10steps / 50steps / tts（teacher-forcing sampling）

**数据集与评分：**

| 数据集 | 评分方式 | train pool | test | 极端方向 |
|---|---|---|---|---|
| GenEval2 GM | soft-TIFA 各维度独立打分后取**几何均值**；任意维度为 0 → 全局分为 0 | 2400 | 800 | 低分堆积（≥20% 趋近 0） |
| GenEval2 AM | soft-TIFA 各维度独立打分后取**算术均值**；维度间可相互补偿 | 2400 | 800 | 无明显极端 |
| UniGenBench | Gemini-Flash 按 testpoint 逐条打分（0/1），跨 seed 均值；评测 prompt 编辑能力 | 2400 | 600 | 高分堆积（≥30% 趋近 1） |

GenEval2 train pool：qwen/flux 为 gen\_perseed（400 条）+ gen2000\_perseed（2000 条）合并去重，共 2400 条；boogu 为单文件 gen2400\_perseed，共 2400 条。test 集：raw\_perseed（800 条），与 train pool 不重叠。UniGenBench train pool：gen2400\_edit\_v2（2400 条）；test：raw600\_edit\_v2（600 条）。

> **GenEval2 AM 与 UniGenBench 的等价性：** 两者均采用"跨维度均值"聚合，分数分布宽松，无强极端堆积（AM 左端接近 0 极少，UniGenBench 右端堆积），后续分析将两者并列对比。

## 1. 分数分布：极端方向决定后续一切

**实验设计逻辑：** 若分数分布在 [0,1] 上均匀或接近正态，则 R²(all) 会均匀反映 predictor 对全值域的预测质量，后续实验无需特殊处理。但若分布严重双极化（大量样本堆积在 0 或 1 附近），则 predictor 只需学会"识别极端"就能获得虚高的 R²(all)，而对真正有决策价值的中间区间一无所知。本节先摸清三个数据集的实际分布，为 §2 的 R²_mid 拆解和后续分析提供基础。

**实验设置：** 直接统计各数据集 test 集（geneval2: 800 条，unigen: 600 条）在三档配置下的分数分布。统计指标为均值、低分比例（y < 0.05）、高分比例（y > 0.95）。阈值 0.05/0.95 与 §2–§3 的极端样本定义一致。

## 2. 全样本 R² 看起来不错，但中间区间直接塌陷

**实验设计逻辑：** §1 已证明分布两端严重堆积。若 predictor 仅靠识别极端样本获得 R²，则对中间区间（真正需要细粒度路由决策的区域）应几乎无效。若两者 R² 相近，说明 predictor 对全值域均匀有效；若 R²_mid ≪ R²(all)，则说明 R²(all) 被极端样本的识别信号虚化，中间区间的预测实际上已经失败。

**实验设置：** 训练集取 pool 中 2200 条（固定 seed=42 shuffle 后去掉 200 条 val），测试集全量（geneval2: 800 条，unigen: 600 条）。α 用 200 条 val 的 R² 选。分别计算全样本 R²(all) 和中间区间 R²_mid（仅对 y\_true ∈ (0.10, 0.90) 的样本计算，下同）。R²_mid 衡量 predictor 对非极端样本的预测能力，排除两端堆积的贡献。每个 run = 一个模型 × 一档配置，单独训练一个 Ridge。

## 3. 加数据只提全样本 R²，无法修复中间区间

**实验设计逻辑：** §2 给出的是最大训练量（n=2200）下的快照。若 §2 的低 R²_mid 是数据量不足造成的，则随训练量增加 R²_mid 应逐步收敛到正值，零/满分 recall 也应持续上升；若数据量增加只改善 R²(all) 而 R²_mid 始终不修复，则说明瓶颈不是数据量，而是信号本身的稀薄——即使给再多样本，predictor 也无法在中间区间做出有效预测。

**实验设置：** LC（learning curve）实验。pool 共 2400 条，固定 seed=42 切出 200 条 val，剩余 2200 条作为 LC pool。n\_train ∈ {100, 300, 600, 1000, 1500, 2200}，每档从 LC pool 中按顺序（非随机采样，保证单调）取前 n 条，用 200 条 val 选 α，在全量 test 上评估。除 R²(all)/R²(mid) 外，还统计极端样本检测：以 y\_pred < 0.05 判为"预测零分"、y\_pred > 0.95 判为"预测满分"，与 y\_true 对应 threshold 计算 precision/recall/F1；本节重点汇报 recall（漏报率）。

training size 从 100 增至 2200，观察 R²(all) 和 R²(mid) 的增长轨迹（§2 已给出 n=2200 终点值，本节聚焦过程）。

## 4. 中间区间本身不可学：四格实验

**实验设计逻辑：** §3 证明加数据无法修复 R²_mid，但原因尚不明确——可能是"训练目标被极端样本支配"（全量训练时极值点的梯度主导，压制了中间区间的学习），而非中间区间信号本身的缺失。若是前者，只用中间区间样本训练（C: mid→mid）应能恢复 R²_mid；若 C 和 B（全量训练、只评估中间区间）结果相近且仍接近零，则说明问题在信号本身——即使消除极端样本的干扰，中间区间内的 prompt 间质量差异对 embedding 仍不可分。

**实验设置：** n\_train = 2200（§3 LC 终点），test 全量。对训练集和测试集分别施加过滤，构造四种组合，每种独立训练一个 Ridge（α 用 200 条 val 选），在对应过滤后的 test 子集上计算 R²。

- **A(all→all)**：无过滤，全量训练 + 全量测试（对照，等价于 §2 的 R²(all)）
- **B(all→mid)**：全量训练，只在 y\_true ∈ (0.10, 0.90) 的 test 子集评估（等价于 §2 的 R²\_mid）
- **C(mid→mid)**：只用 y\_true ∈ (0.10, 0.90) 的训练样本（约占 pool 的 40–65%），在相同中间区间 test 子集评估；用于判断 B 的低 R²\_mid 是否因训练目标被极端样本主导
- **D(bal→bal)**：按 y\_true 切 5 等频 bin（quantile），每 bin 取相同数量样本（min\_n = 最少 bin 的样本数）组成均衡训练集，在相同均衡 test 子集评估；消除基率效应，但损失样本量

## 5. 类别内打乱：predictor 依赖 prompt 级排序信号

**实验设计逻辑：** 若 predictor 的路由收益来自**类别均值差异**（粗粒度），则在训练集内按类别打乱标签（保留类别均值不变，只破坏类别内 prompt 间的排序）后，路由 quality 应基本不变；若来自**类别内 prompt 级精细差异**，则打乱后 predictor 应失效。

**实验设置：** 训练集 2200 条，test 全量。对训练集按 prompt 类别（GenEval2 的 skill 类别 / UniGenBench 的 testpoint 类型）分组，在每个类别内部对所有配置的得分标签独立 permute（**保留类别均值不变**，破坏 prompt 内的跨配置排序关系），重复 5 次取均值，与原始 predictor 的路由结果对比。路由框架：**三个独立 3 档路由实验**（qwen/boogu: cost=[10,50,100]，budget=50；flux: cost=[23.1,115.5,231]，budget=115.5），Lagrangian relaxation sweep lambda，quality@budget 用线性插值。打乱只影响训练标签，不影响 test 集；R²(all) 和 R²(mid) 也用打乱后 predictor 在原始 test 标签上计算。

散点图揭示打乱机制的直接效果：

- **打乱后 predictor**（右列）：点云完全水平散布，R² 全面翻负——类别内打乱后 embedding 与标签的对应关系被彻底破坏，predictor 退化为近常数输出。

1. **predictor 的信号来自类别内 prompt 级排序**，而非类别均值差异。打乱保留了所有类别均值，若 predictor 依赖类别均值路由，则打乱后应无损；但实验结果是 R² 全面崩塌、路由跌破 LP，说明信号的真正来源是类别内各 prompt 之间的质量排序，而非类别间均值的粗粒度区分。

2. **打乱后路由跌破 LP 基线**（UniGen qwen: ridge_shuf=0.795 < lp=0.821；GM qwen: 0.324 < 0.332），predictor 变成误导性的噪声而非有用信号——路由被错误预测导向了差的档位。

3. **abs drop 与原始收益比例接近**：UniGen qwen 原始 +0.045 vs LP，打乱后 −0.026，drop=0.071，几乎抹去全部收益并进入负区间；GM flux 原始增益本就极小（+0.001），打乱后亦只跌 0.005，pattern 一致。

综合结论：**predictor 对路由的贡献是真实的**（相当于原始 vs LP 的增益），但这一贡献来自类别内 prompt 级排序信号——训练标签的类别内相对顺序被破坏时，收益不是"减少"而是完全消失并变为负向。

## 6. 高 R² 不转化为决策收益：路由 quality learning curve

**实验设计逻辑：** §2–§4 均在预测质量（R²）层面分析，但最终目标是路由决策收益。若 predictor 虽然 R²(all) 偏高但 R²_mid 极低，是否会如实反映在路由 quality 的提升幅度上？若路由收益（ridge − LP）随训练量增加而持续增长，则"R² 低不代表无用"；若路由 LC 与 R² LC 趋势一致（都早早平坦），则说明 R²_mid 对路由质量是有效代理，§2–§4 的结论在决策层面同样成立。

**实验设置：** 9 组 intra-model（qwen/flux/boogu × gm/am/unigen），每组 3 档路由（model × 10/50/tts），Lagrangian relaxation 路由，与 §7 相同框架。

数据划分：pool 共 2400 条（qwen/flux geneval2：gen\_perseed 400 + gen2000\_perseed 2000；boogu geneval2 / 各 unigen：单文件 2400），固定 seed=42 shuffle 后切 200 条作 external val，剩余 2200 条作 LC pool。n\_train = 200/400/800/1200/1600/2000/2200，每档重复 3 seeds（从 2200 中随机采样），均值汇报。alpha（1/10/100/1000）用 external val R² 选，与 §2–§4 完全对齐。test 集独立（geneval2: 800 条 raw\_perseed；unigen: 600 条 raw），全程不参与训练或调参。LP baseline 用全 pool（2400）均值估计。

**观察：**

- **两种截然不同的 LC 模式**：GM/AM 类从 n=200 开始 recovery 就基本达到终点水平（GM qwen: 17%→26%，几乎 n=200 即收敛），加再多数据收益极小；UniGen 类则随数据量**持续线性增长**，n=200 时仅 0~9%，n=2200 时已达 41~48%，且曲线在 2200 处仍未见明显收敛——如果有更多数据，UniGen 的路由收益还会继续提升。

- **GM/AM 的瓶颈是信号，不是数据量**：n=200 就接近收敛，说明极少数据就已"学完"所有可用信号（主要是类别级均值差异），继续添加数据只是重复同一信号，不引入新的可分信息。这与 §3 的 R² LC 规律一致——R²(all) 也在低 n 就接近收敛。

- **UniGen 的路由收益随数据增长的原因**：UniGen 的分数分布比 GM 更连续（高分比例虽高，但中间区间样本更多），prompt 级排序信号密度更高，更多训练样本能持续覆盖新的类别内排序模式，而非重复已见过的极端样本。

- **flux/GM 和 boogu/AM 的负 recovery**：预测信号极弱时，predictor 引入的噪声反而误导路由，结果比无监督的 LP 还差（boogu/AM n=200 时 −13%，全程未转正到有意义水平）。加数据可以轻微减小负向幅度（boogu/AM 从 −19% 改善到 −9%），但无法根本翻转。

- **结构性问题 vs 数据量问题的判定标准**：若路由 LC 在低 n 就平坦，则是结构性问题（信号耗尽）；若持续上升直到最大 n，则是数据量限制。GM/AM 属于前者，UniGen 属于后者——两者的改善路径完全不同：前者需要更好的特征或评分方式，后者可以从扩大训练集中受益。

## 7. mid→mid 路由：中间区间的 predictor 能否改善路由决策？

**实验设计逻辑：** §4 证明中间区间信号稀薄，§5 证明 predictor 依赖的是类别内 prompt 级排序信号。两者合并引出一个问题：如果在路由时只对中间区间样本训练 predictor（Ridge(mid)，仅用 y\_true ∈ (0.10, 0.90) 的训练样本），是否能把原本被极端样本"稀释"的排序信号集中到中间区间，从而提升路由决策质量？若 Ridge(mid) 的 quality 系统性高于 Ridge(all)，则说明极端样本的干扰是路由瓶颈；若两者相近或 Ridge(mid) 更差，则进一步证实 §4 结论——中间区间的信号不足是本征问题，与极端样本无关。

**实验设置：** 训练集 2200 条（seed=42 切 val 后剩余），test 全量。路由框架与 §5/§6 相同：Lagrangian relaxation，sweep lambda ∈ linspace(−0.005, 0.1, 8000) ∪ {0.5, 1, 100, −1}，每个 lambda 对每条样本 argmax(predicted\_score − λ × cost) 决定分配档位，统计全 test 集平均 cost 和平均 quality，最终在 (avg\_cost, avg\_quality) 曲线上用线性插值取 budget 处的 quality。

- **预算与成本**：intra-model budget = 50（qwen/boogu）或 115.5（flux）；cross-model budget = 50，9 档 cost = [10, 50, 100, 23.1, 115.5, 231, 10, 50, 100]
- **LP baseline**：在训练集均值构成的 (cost, quality) 凸包上插值，budget 处混合最近两档；理论最优的无监督 baseline
- **OC baseline**：训练集中每条样本按 argmax(true\_score) 分配最优档，统计各档被选概率，test 集按同比例随机分配；衡量"如果训练集分布完全代表 test"的上界，但实际因分布偏移而低于 LP
- **Ridge(all)**：全 2200 条训练，α 用 200 条 val 选，sweep lambda 路由
- **Ridge(mid)**：只用 y\_true ∈ (0.10, 0.90) 的训练样本（约 800–1400 条），α 用 200 条 val 中同样过滤后的子集选，sweep lambda 路由；与 Ridge(all) 的唯一区别是训练集过滤
- **数据集**：GenEval2 GM / GenEval2 AM / UniGenBench，3 × 3 = 9 组 intra-model + 3 组 cross-model

### 7.1 单模型内路由（intra-model，10/50/tts × 3 数据集）

Lagrangian 下 tts（cost=100）不直接被 hard-exclude，而是通过 lambda 惩罚参与竞争；预算内平均 cost = 50 时可混合分配 10/50/tts。

| 设置 | LP | OC | Oracle | Ridge(all) | Ridge(mid) | gap_mid−LP |
|---|---|---|---|---|---|---|
| qwen / GM    | 0.3321 | 0.3282 | 0.4476 | 0.3604 | 0.3366 | +0.0045 |
| flux / GM    | 0.3236 | 0.3246 | 0.3837 | 0.3245 | 0.3222 | −0.0015 |
| boogu / GM   | 0.3923 | 0.3965 | 0.5019 | 0.4080 | **0.4090** | +0.0167 |
| qwen / AM    | 0.7645 | 0.7624 | 0.8136 | 0.7761 | 0.7740 | +0.0095 |
| flux / AM    | 0.7507 | 0.7513 | 0.7779 | 0.7536 | 0.7535 | +0.0028 |
| boogu / AM   | 0.8130 | 0.8017 | 0.8458 | 0.8054 | 0.8075 | −0.0055 |

**观察：**
- Ridge(all) 在 UniGen 上明显超过 LP（+0.040/+0.022/+0.024），说明 UniGen 存在可学信号；在 GM 上也有 +0.016 左右的提升。
- Ridge(mid) 与 Ridge(all) 相比多数略低——mid 训练样本减少后，对非极端区间的预测稍差，但差距有限（≤0.035）。
- Ridge(mid)−LP 多数为正（+0.005~+0.017），只有 boogu/AM 和 flux/GM 略为负。

### 7.2 跨模型路由（cross-model，9 档：qwen/flux/boogu × 10/50/tts）

9 档 Lagrangian 路由，lambda sweep 同时决定跨模型的分配比例。

| 数据集 | LP | OC | Oracle | Ridge(all) | Ridge(mid) | gap_all | gap_mid |
|---|---|---|---|---|---|---|---|
| GM      | 0.3934 | 0.3107 | 0.5867 | **0.4082** | 0.3863 | +0.0148 | −0.0071 |
| AM      | 0.8130 | 0.7567 | 0.8725 | 0.8062 | 0.8074 | −0.0068 | −0.0056 |
| UniGen  | 0.8887 | 0.8132 | 0.9701 | **0.9237** | 0.8766 | +0.0350 | −0.0121 |

**观察：**
- Oracle−LP gap 在跨模型路由下显著放大（GM +0.193，UniGen +0.081），说明跨模型路由的理论收益很大。
- Ridge(all) 在 GM/UniGen 上**超过 LP**（+0.015/+0.035），说明全量训练的跨模型路由有效——predictor 能识别"哪类 prompt 更适合哪个模型/档位"这一粗粒度信号。
- Ridge(mid) 在跨模型场景下明显弱于 Ridge(all)（gap 约 −0.02~−0.05），说明 mid 训练样本不足以支撑 9 档高维路由，mid 区间的交叉模型信号不足。
- OC 全面低于 LP——训练集分布（gen2400）与 test（raw800/raw600）的 argmax 分布不一致，导致 OC 分配错位。

| §6 四档（qwen+flux×10/50） | UniGen | 0.815 | 0.843 | 0.873 | 47.7% |

| §7 cross                   | UniGen | 0.889 | 0.924 | 0.970 | +42% |

**结论：** Ridge(all) 在正确实现 Lagrangian relaxation 后，intra-model 和 cross-model 路由均能超过 LP；UniGenBench 的 recovery 接近 50%，说明"哪类 prompt 偏好高质量模型"这一粗粒度信号确实可学。但 Ridge(mid) 相比 Ridge(all) 无系统性优势，说明**中间区间的精细信号不比全量更强**，问题不在极端样本污染训练目标，而在于 mid 区间信号本身的信息量不足。

散点图揭示 mid 训练的直接效果：

## 总结

| 层次 | 现象 | 关键数据 |
|---|---|---|
| **极端样本驱动 R²** | GM R²(all) 0.29–0.51 靠低分识别；UniGen R²(all) 0.13–0.43 靠满分识别；驱动方向由分布特性决定 | 分布表（第 1 节）+ R² 拆解（第 2 节） |
| **中间区间是共同上限** | 去掉两端后，所有数据集 / 评分 / 模型的 R²_mid 均迅速衰竭；tts 类分布更极端，衰减也更快 | 第 2 节 R²_mid 表 |
| **加数据只改误报率** | zero/one recall 随训练量增长有限；另一端 recall 全程趋近 0；R²_mid 不修复 | 第 3 节 LC 表 |
| **中间区间信号本身稀薄** | C(mid→mid) 与 B(all→mid) 接近，说明问题不在训练目标偏置 | 第 4 节四格表 |
| **收益来自类别内排序** | 类别内打乱后 R² 全面翻负且路由跌破 LP 基线（类别均值完全保留仍失效），说明收益来自类别内 prompt 级排序信号而非类别间均值差异 | 第 5 节打乱实验 |
| **加数据的效果分两类** | GM/AM：n=200 即收敛，加数据无益（信号耗尽）；UniGen：持续线性增长至 n=2200 仍未平坦，可从扩大训练集受益 | 第 6 节路由 LC |
| **mid 训练无系统优势** | Ridge(mid) 与 Ridge(all) 相近，intra-model 场景 mid 略低，无法证明 mid 训练优于全量 | 第 7 节 mid 路由表 |

**核心结论：** predictor 学到的是"prompt 是否落入极端分布"，而非"prompt 的具体质量是多少"。Lagrangian 路由下 Ridge(all) 能超过 LP（UniGen recovery ~50%），这一收益来自类别内 prompt 级排序信号（§5 证明类别均值差异对路由贡献为零）；但该信号仅覆盖极端区间，中间区间无论用何种训练策略，精细预测均无法实现。
